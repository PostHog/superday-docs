# Generate test errors

To practice debugging with MCP, you need some errors to work with. Let's create a simple Next.js app with intentional bugs.

Already have a PostHog project with production data? You can skip this page and start [debugging with AI and MCP](/docs/mcp-tutorial/debug-with-mcp)!

## Configure PostHog

To prepare your app to capture errors, create a provider:

```typescript
export function ErrorTrackingProvider({ children }) {
  // Initialize error tracking
  return <>{children}</>
}
```

Then, wrap your app with it:

```typescript
export default function RootLayout({ children }) {
  return (
    <ErrorTrackingProvider>
      {children}
    </ErrorTrackingProvider>
  )
}
```

## Verify in PostHog dashboard

Check your PostHog dashboard to confirm that your test errors were captured:

1. Go to [PostHog errors](https://us.posthog.com/error_tracking).
2. You should see your test errors appear within a few minutes.
3. Click into an error to see the full stack trace.
