## Prerequisites

Before you begin, make sure you have:

- **PostHog account**: [Sign up free](https://us.posthog.com/signup) if you don't have one
- **AI assistant**: [Claude Desktop](https://claude.ai/download), [Cursor](https://cursor.sh/), [Windsurf](https://codeium.com/windsurf), or another AI assistant of your choice
- **Node.js**: [Download](https://nodejs.org/en/download) only needed if you're [generating test errors later](/docs/mcp-tutorial/generate-errors)

## Step 1: Get your personal API key

You need a **personal API key** (not a project API key) to use the PostHog MCP server:

1. Go to [PostHog Settings > Personal API Keys](https://us.posthog.com/settings/user-api-keys).
2. Click **+ Create personal API key**.
3. Name it something like `MCP Server`.
4. Give it fine-grained permissions.
5. Copy the key immediately (you won't see it again).

:::warning Warning
We recommend giving your API key fine-grained permissions for enhanced security. Do not share your key or commit it to your project.
:::

## Step 2: Install the PostHog MCP server

PostHog offers two installation methods for the MCP server:

- **Quick install (recommended)**: Use the [PostHog MCP wizard](https://posthog.com/docs/model-context-protocol#quick-install-using-the-posthog-wizard) for guided setup
- **Manual install**: Follow the [manual installation guide](https://posthog.com/docs/model-context-protocol#manual-install) if you prefer full control

Choose whichever method works for you, then come back here to verify it works.

## Step 3: Restart your AI client

Close and reopen your AI assistant completely. This loads the new MCP configuration.

## Step 4: Verify it works

Let's test the connection with three quick prompts.

### List MCP tools

**Prompt:**
```text
What PostHog MCP tools are available?
```

**Expected response:** Your AI should list tools like `list-errors`, `get-error-details`, `feature-flag-get-all`, etc.

### List projects

**Prompt:**
```text
List my PostHog projects
```

**Expected response:** You should see your project name and ID.

### Query errors

**Prompt:**
```text
Show me the most recent errors in my PostHog project
```

**Expected response:** 
- If you have errors: A list of recent exceptions
- If you don't: A message saying no errors found (we'll generate some next!)

- MCP tools are listed
- Your project appears
- Error query runs (even if empty)
